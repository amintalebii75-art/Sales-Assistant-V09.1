دستیار فروش گرانول برتر — V07.8.0
مرحله ۹: Release یکپارچه Smoke Test پایلوت

هدف این نسخه
- تبدیل چک‌لیست پراکنده تست به یک صفحه عملیاتی واحد.
- اجرای بررسی‌های خودکار خواندنی برای PHP، Session، CSRF، دیتابیس، جدول‌ها و فایل‌های رابط.
- ثبت PASS / FAIL / BLOCKED / NOT RUN برای چهار نقش.
- نگهداری نتایج در مرورگر و دانلود گزارش JSON برای ادامه پروژه.
- جلوگیری از انتقال زودهنگام به هاست تا زمان PASS شدن تمام تست‌های الزامی.

فایل جدید
- pilot_test.php
- assets/css/v07-pilot-test.css
- assets/js/v07-pilot-test.js

تغییرات رابط
- لینک «آزمون پایلوت» در منوی اصلی و منوی موبایل.
- لینک آزمون در صفحه Summary-only ناظر مدیریتی.
- Badge نسخه به V07.8 تغییر کرده است.

امنیت و داده
- این صفحه هیچ عملیات نوشتن روی دیتابیس انجام نمی‌دهد.
- اطلاعات اتصال، رمز، CSRF و محتوای Full-State نمایش داده نمی‌شود.
- Restore، ساخت کاربر و تغییر Permission از این صفحه انجام نمی‌شود.
- هیچ SQL یا Migration جدیدی لازم نیست.

نصب روی XAMPP
1) پوشه را داخل C:\xampp\htdocs قرار بده.
2) config.php نسخه فعال را در ریشه این نسخه کپی کن.
3) فونت‌های دارای مجوز را از نسخه محلی به assets\fonts کپی کن.
4) login.php را باز کن و وارد حساب مدیر شو.
5) از منوی سیستم «آزمون پایلوت» را باز کن.
6) بررسی خودکار را ببین و بعد با چهار حساب تست‌ها را ثبت کن.

وضعیت Release
نامزد Smoke Test یکپارچه روی XAMPP؛ انتقال به هاست فقط پس از PASS کامل و نبود FAIL/BLOCKED.
