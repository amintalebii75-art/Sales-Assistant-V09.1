نسخه V07.1.0 — فاز دوم انتقال کنترل‌شده UI آریانا

اولویت اجراشده:
1) صفحه مشتریان
2) پرونده و تاریخچه مشتری
3) رفع ابهام منوی تکراری ثبت مذاکره

نصب روی localhost:
1. پوشه را داخل C:\xampp\htdocs قرار دهید.
2. config.php نسخه فعال قبلی را داخل این پوشه کپی کنید.
3. فایل‌های فونت IRANSansXFaNum را از نسخه قبلی به assets\fonts کپی کنید.
4. دیتابیس و SQL را تغییر ندهید.
5. login.php را باز کنید و با Ctrl + F5 تازه‌سازی کامل انجام دهید.

لینک پیشنهادی:
http://localhost:8080/Sales-Assistant-V07-1-0-Ariana-Customers-Phase2/login.php
