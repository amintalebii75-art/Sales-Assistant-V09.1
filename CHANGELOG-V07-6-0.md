# V07.6.0 — Ariana Users, RBAC & Customer Access

## Scope
Controlled presentation and usability redesign of the users, roles, permission overrides, customer access and audit workspace.

## Changed
- Ariana command header and security summary metrics.
- Search and filter controls for user accounts.
- Role, account status and RBAC review badges.
- Responsive user cards for mobile screens.
- Grouped Persian permission labels while preserving original permission keys.
- Redesigned permission override modal.
- Customer access summaries for View, Call and Edit.
- Customer search, select-all and clearer Grant/Revoke controls.
- Redesigned security audit table and mobile cards.

## Not changed
- Database schema or migrations.
- users_api.php request and response contracts.
- Server-side authorization, CSRF and audit enforcement.
- Role defaults and permission semantics.
- Customer Access ownership and scope rules.
