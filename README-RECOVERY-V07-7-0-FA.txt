وضعیت:
- هسته عملیاتی V06.0.9 حفظ شده است.
- فازهای رابط آریانا تا V07.7.0 در این نسخه تجمیع شده‌اند.
- Validation استاتیک موفق است.
- Smoke Test کامل مرورگر روی XAMPP و دیتابیس واقعی هنوز باید اجرا شود.

نصب localhost:
1) پوشه را داخل C:\xampp\htdocs قرار دهید.
2) config.php نسخه فعال قبلی را در ریشه این پوشه کپی کنید.
3) فایل‌های فونت محلی دارای مجوز را در assets\fonts کپی کنید.
4) هیچ SQL یا Migration جدیدی اجرا نکنید.
5) login.php را باز کنید و Ctrl+F5 بزنید.
