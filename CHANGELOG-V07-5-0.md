# V07.5.0 — Ariana Planning & Team Tasks

## Scope
Presentation-only redesign of the four-week monthly planning workspace.

## Changed
- Ariana dark command header for planning.
- Redesigned monthly plan hero and visual progress ring.
- Modern four-week cards with task, completion, blocked and progress summaries.
- Redesigned weekly task rows, assignment chips and manager actions.
- Improved team KPI cards and performance tables.
- Improved personal task and manager-viewer summary presentation.
- Responsive layout for desktop, tablet and mobile.

## Not changed
- Database schema and migrations.
- Planning API payloads and permissions.
- Revision/concurrency rules.
- Assignment, publish, copy, close, archive and reactivation logic.
- Jalali date behavior.
