دستیار فروش گرانول برتر — V07.7.0
فاز ۸: تنظیمات، پشتیبان/بازیابی و آمادگی استقرار

این نسخه بر پایه V07.6.0 ساخته شده و منطق دیتابیس، RBAC، Customer Access، Planning، تاریخ شمسی و ثبت مذاکره را تغییر نمی‌دهد.

تغییرات اصلی
1) بازطراحی کامل صفحه تنظیمات با UI آریانا.
2) نمایش وضعیت همگام‌سازی، Revision، محیط اجرا و Recovery مرورگر.
3) جداسازی تنظیمات سازمان از تنظیمات شخصی مرورگر.
4) اعمال محدودیت نمایشی: تغییر تنظیمات سازمان فقط برای مدیر دارای settings.manage و state.save_full.
5) مرکز پشتیبان و انتقال داده شامل Recovery، نسخه مرورگر، CSV و خروجی تحلیل.
6) نمایش خلاصه سه Backup اخیر سرور برای مدیر مجاز.
7) حفظ Restore کنترل‌شده با CSRF، Permission، Revision و Backup خودکار پیش از Restore.
8) چک‌لیست استقرار واقعی شامل config.php، HTTPS، Backup دیتابیس، Smoke Test چهار نقش و Error Log.
9) تقویت .htaccess با Security Headerها و مسدودسازی فایل‌های حساس/پوشه‌های مخزن.
10) رفع لینک خراب CSS در index.php و به‌روزرسانی Badge نسخه به V07.7.

نصب روی XAMPP
1) پوشه را داخل C:\xampp\htdocs قرار بده.
2) config.php نسخه فعال قبلی را داخل پوشه جدید کپی کن.
3) پوشه assets\fonts نسخه قبلی را داخل نسخه جدید کپی کن.
4) هیچ SQL یا Migration جدیدی لازم نیست.
5) لینک login.php پوشه جدید را باز کن و Ctrl+F5 بزن.

نکته امنیتی
- فایل create_admin.php عمداً داخل Release وجود ندارد.
- اطلاعات واقعی دیتابیس و فونت‌های دارای مجوز داخل ZIP توزیع نشده‌اند.
- Restore کامل سازمان فقط برای مدیر دارای مجوزهای لازم قابل مشاهده و اجرا است.

وضعیت
آماده پایلوت واقعی و استقرار محدود کنترل‌شده؛ انتشار عمومی فقط پس از تکمیل موارد دستی چک‌لیست استقرار.
