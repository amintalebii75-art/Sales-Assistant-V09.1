دستیار فروش گرانول برتر — V08.0.0
نسخه کامل یکپارچه برای نصب یک‌باره روی localhost

هدف این بسته
این نسخه تمام بخش‌هایی را که تا V07.8 ساخته شده‌اند در یک پوشه واحد نگه می‌دارد؛ دیگر لازم نیست Patchها یا نسخه‌های مرحله‌ای را جداگانه روی هم کپی کنید.

بخش‌های یکپارچه
- ورود، Session، CSRF، RBAC و نقش‌های مدیر، بازاریاب، مرکز تماس و ناظر مدیریتی
- Customer Access با سطوح View / Call / Edit
- مرکز فرمان و گزارش عملکرد
- مشتریان در نمای کارت، جدول و قیف کامل هشت‌مرحله‌ای
- پرونده مشتری، تاریخچه مذاکرات، پیگیری‌ها، سفارش‌ها و یادداشت‌ها
- ثبت مذاکره چندنتیجه‌ای با نمایش واضح انتخاب‌ها
- گزینه‌های پیش‌فرض مذاکرات + گزینه‌های سفارشی قابل افزودن توسط مدیر
- ارجاع نتیجه مرکز تماس به بازاریاب مسئول
- برنامه ماهانه چهار هفته‌ای، وظایف، Assignment، پیشرفت و تاریخچه
- مدیریت کاربران، Permissionها و دسترسی مشتریان
- تنظیمات، Backup/Restore و چک‌لیست استقرار
- آزمون پایلوت خودکار و دستی چهار نقش
- تاریخ‌های شمسی و فونت IRANSansXFaNum در صورت کپی فایل‌های مجاز محلی

نصب یک‌باره روی XAMPP
1) پوشه کامل را داخل C:\xampp\htdocs قرار بده.
2) فایل config.php نسخه‌ای که الان روی localhost درست کار می‌کند را در ریشه همین پوشه کپی کن.
3) فایل‌های فونت محلی خودت را داخل assets\fonts کپی کن.
4) هیچ Patch دیگری روی این نسخه نصب نکن.
5) هیچ SQL جدیدی اجرا نکن؛ این نسخه با دیتابیس فعلی granule_sales_local ساخته شده است.
6) Apache و MySQL را روشن کن.
7) login.php را باز کن.
8) بعد از ورود، تمام بخش‌ها را در استفاده واقعی تست کن و ایرادها را گزارش بده.

لینک پیشنهادی
http://localhost:8080/Sales-Assistant-V08-0-0-Full-Integrated-Localhost-Pilot/login.php

نکته مهم
- این نسخه برای پایلوت واقعی روی localhost است، نه Production عمومی.
- نسخه قبلی V06.0.9 را پاک نکن؛ فقط به‌عنوان Rollback نگه دار.
- از این مرحله به بعد، فقط روی همین شاخه V08 اصلاح انجام می‌شود و نسخه‌های نمایشی مرحله‌ای متوقف شده‌اند.
