شروع از اینجا — V09.1.0
فرم‌های قابل تنظیم و اطلاعات پایه

این نسخه یک Full Release مستقل بر پایه V09.0.0 است.

نصب localhost:
1. پوشه را داخل C:\xampp\htdocs قرار بده.
2. config.php نسخه سالم V09 را داخل ریشه این پوشه کپی کن.
3. فونت‌های موجود خودت را داخل assets\fonts کپی کن.
4. SQL جدید اجرا نکن.
5. login.php را باز کن.
6. با مدیر وارد شو و از «سیستم ← فرم‌ها و اطلاعات پایه» شروع کن.

نکته:
- V09 قبلی را پاک نکن؛ Rollback است.
- تنظیمات فرم در app_state ذخیره می‌شوند.
- مخفی‌کردن فیلد یا غیرفعال‌کردن گزینه، داده قبلی را پاک نمی‌کند.
- تنظیم UI هیچ Permission جدیدی ایجاد نمی‌کند.
