# راهنمای V09.1 — فرم‌ها و اطلاعات پایه

## نصب روی localhost

1. پوشه نسخه V09.1 را جدا از V09 نگه دارید.
2. `config.php` نسخه سالم V09 را در ریشه V09.1 کپی کنید.
3. فایل‌های فونت موجود در رایانه خود را داخل `assets/fonts` کپی کنید.
4. SQL جدید اجرا نکنید.
5. وارد حساب مدیر شوید.
6. از منوی **سیستم ← فرم‌ها و اطلاعات پایه** وارد صفحه جدید شوید.

## مدیریت فیلدها

برای هر فیلد می‌توان این موارد را تعیین کرد:

- نمایش یا عدم نمایش
- اجباری یا اختیاری
- نمایش برای مدیر
- نمایش برای بازاریاب
- نمایش برای مرکز تماس

فیلدهای دارای نشان «سیستمی» خاموش نمی‌شوند تا فرم قابل ثبت باقی بماند.

## مدیریت اطلاعات پایه

هر فهرست یکی از سه حالت را دارد:

- **فقط مدیر:** کاربر عادی دکمه افزودن ندارد.
- **پیشنهاد با تأیید مدیر:** پیشنهاد کاربر Pending می‌شود و تا تأیید مدیر برای تیم دیده نمی‌شود.
- **افزودن مستقیم:** گزینه همان لحظه برای تیم فعال می‌شود.

مدیر می‌تواند گزینه را تأیید، رد، تغییر نام، غیرفعال یا دوباره فعال کند.

## نکته مهم

خاموش‌کردن فیلد یا گزینه، داده قبلی را حذف نمی‌کند. اگر مقداری از نسخه قبلی دیگر در فهرست فعال نباشد، داخل فرم با عنوان «ثبت قبلی» نمایش داده می‌شود.

## تست پیشنهادی

1. مدیر فیلد «بسته‌بندی» را خاموش کند و فرم مشتری را باز کند.
2. مدیر دوباره آن را روشن و اجباری کند؛ ذخیره بدون انتخاب باید متوقف شود.
3. حالت «نحوه آشنایی» را روی «پیشنهاد با تأیید مدیر» بگذارد.
4. بازاریاب با `+` یک گزینه پیشنهاد کند.
5. مدیر آن را تأیید کند.
6. بازاریاب دوباره وارد فرم شود و گزینه تأییدشده را ببیند.
7. مرکز تماس روی مشتری دارای سطح `view` نباید بتواند مذاکره ثبت کند.
8. پس از تغییر سطح به `call`، ثبت مذاکره باید ممکن باشد.
